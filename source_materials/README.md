# Source materials

Original working files for the systematic review, copied from the local folder `Paper 1_full docs and info/` on 1 October 2026 for backup.

| Folder | Contents |
|---|---|
| `register/` | Included-studies register (April 2026), several sheets |
| `protocol/` | Registered PROSPERO protocol (form text) and full protocol, as registered. The October 2026 amended versions are in `review/protocol_amended/` |
| `drafts/` | Word drafts of the manuscript, sections, tables, table of contents, visual plan, PRISMA notes, reference list and June 2026 cover letter |
| `figures/sources/` | Figure source files (PNG, SVG, editable PPTX/XLSX) |
| `figures/latex_figures/` | Figure images used by the earlier LaTeX build |
| `latex_extras/` | Appendix and figure .tex files not in the main LaTeX tree |
| `working_notes/` | Status and checklist notes from earlier editing sessions. Several claims in these notes were later found to be wrong; see `review/NMI_readiness_review.md` |

Not copied: third-party paper PDFs (copyrighted; re-downloadable), LaTeX build files (.aux/.log/.bbl), and files that duplicate ones already in the repository.
