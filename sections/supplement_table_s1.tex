\textbf{Column Definitions:}
\begin{itemize}
    \item \textbf{ID}: Sequential study identifier (1-71)
    \item \textbf{Authors}: Lead author(s) and year
    \item \textbf{Yr}: Publication year
    \item \textbf{Modality}: Neural recording type (ECoG, Intracort., EEG, MEG, fMRI, sEEG, HD-sEMG, Hybrid)
    \item \textbf{N}: Number of human participants
    \item \textbf{Task Type}: Overt speech, Imagined speech, Attempted speech, Perceived speech, Phoneme classification, Event detection, Semantic reconstruction, etc.
    \item \textbf{Architecture}: Traditional ML, CNN, LSTM, RNN, Seq2Seq, Transformer, Self-supervised, LLM-integrated, Foundation Models
    \item \textbf{Metric}: Primary performance metric (WER, CER, Acc, Corr, WPM, BLEU, ROUGE, MOS, CIL)
    \item \textbf{Performance}: Numerical value of primary metric
    \item \textbf{Generalization}: Cross-participant (Cross-part), Cross-session (Cross-sess), Cross-language (Cross-lang), Long-term stability (Long-term), or None
    \item \textbf{Code}: Code availability (Yes/No)
    \item \textbf{QS}: Quality Score (0-7 scale; $\geq 5.5$ = High, 3.5-5.0 = Moderate, <3.5 = Low)
\end{itemize}

\vspace{1cm}

\textbf{Notes on Data Gaps:}
\begin{itemize}
    \item Studies without complete PRISMA database extraction are marked with placeholder values derived from paper text
    \item Verify N, Task Type, and Architecture against PRISMA extraction register
    \item Code/Data availability should be confirmed from supplementary materials
    \item Quality Scores reflect adapted 7-item checklist; verify against individual study assessments
\end{itemize}
